# CYBERSHIELD — Product Roadmap

## Completed Milestones (Current Release)
- [x] **Monorepo Foundation:** FastAPI backend, Pydantic v2 settings, Argon2id security primitives, PostgreSQL & SQLite support, Vite + React 18 + TS frontend.
- [x] **Online Crime Analyzer:** Heuristic pattern classification, urgency triggers, indicator extraction.
- [x] **Safe Phishing Inspector:** Zero-trust SSRF protection layer, Shannon entropy DGA detection, Indian bank/UPI typosquatting.
- [x] **Financial Fraud Engine:** 3-layer architecture (Layer A Rules, Layer B Isolation Forest & Random Forest, Layer C Aggregator).
- [x] **Online Abuse Classifier:** Multi-label context-aware classifier with victim-quotation resilience.
- [x] **Threat Intelligence DB:** Deduplication, defanging, and exponential half-life confidence decay.
- [x] **NetworkX Graph Engine:** Connected components, degree centrality, greedy modularity community clustering.
- [x] **Digital Evidence Vault:** SHA-256 cryptographic hashing, path traversal guards, ReportLab PDF assistance report export.
- [x] **Public Cyber Safety Center:** Practical prevention guides + official Indian emergency numbers (1930, cybercrime.gov.in).
- [x] **DevSecOps Pipeline:** GitHub Actions CI/CD workflow, Bandit SAST scanner, Docker Compose, 22-test automated suite.
